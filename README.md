# Game_of_bones

A 3D shooter game with first person view and top down view.
It's a zombie shooter, and the player has 2 guns to kill zombies and ghosts.

## How this was made

I think it's obvious that it was made with Godot and GDScript, also I almost forget my bro "Blender".
Blender was used to convert animations formats to gltf

## Why I made this
I wanted to make my first 3D game in my life... to be honest it's not my first 3D game, but it's my first 3D game in godot. For that reason, I wanted to gain some experience with Godot and enjoy developing a game.

I love making games, because it gives me the opportunity to build whatever ideas I have. I also don't forget to put some easter eggs!

### Things I implemented

1. Creating the player, movement, camera, and camera shake
2. Adding guns and shooting mechanics (bullets, damage, and collisions)
3. Making enemies such as in my game, zombies and ghosts
4. Enemy hits, player health, and Deathscreen
5. Building the map/level 
6. Main menu and settings
7. Music and sounds
8. exporting the game

## How to play

Download the game from: https://remago624.itch.io/game-of-bones

Extract the ZIP and run the game's `.exe`.

## Controls

- WASD - Movement
- Mouse - Look / Aim
- Left Mouse Button - Shoot
- R - Reload
- Shift - Sprint
- Ctrl - Crouch
- Space - Jump
- Tab - Switch camera
- Esc - Mouse visible
- F11 - Fullscreen
- F12 - Show FPS

## System Requirements

- OS: Windows 10/11 64-bit
- CPU: A 4-core CPU is recommended
- RAM: 8 GB
- Storage: 350 MB
- GPU: A dedicated GPU is recommended

## Running from source

1. Clone this repository: https://github.com/Remago624/Game_of_bones
2. Open the project in Godot.
3. Run the project.
